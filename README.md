# YouTube → MP3

Petite application Windows pour convertir des vidéos et playlists YouTube en MP3 (jusqu'à 320 kbps, pochette incluse).

## Installation
1. Téléchargez **[YouTube-MP3.zip](https://github.com/AskipLudo/youtube-mp3/releases/latest/download/YouTube-MP3.zip)**.
2. Décompressez le dossier (clic droit > Extraire tout), dans Documents ou sur le Bureau.
3. Lancez `YouTube-MP3.exe`.

L'application se met à jour toute seule : un bandeau s'affiche quand une nouvelle version est disponible.

Usage personnel uniquement : ne téléchargez que des contenus dont vous avez les droits.
